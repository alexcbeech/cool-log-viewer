# Security Policy

## Supported versions

Security fixes are applied to the latest published release and the current `main` branch. Older releases may not receive backports.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/alexcbeech/cool-log-viewer/security/advisories/new) to report the issue confidentially. Include:

- The affected version or commit.
- Reproduction steps or a proof of concept.
- The expected and observed behavior.
- The potential impact.
- Any suggested mitigation, if known.

You should receive an acknowledgment within seven days. Please allow time to investigate and prepare a fix before publicly disclosing the issue.
